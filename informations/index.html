Inventaires

QR Code

Accès par QR Code

Synchronisation temps réel

Plusieurs personnes, un seul inventaire, en même temps.

L'ensemble de l'application fonctionne en temps réel : plusieurs bénévoles peuvent réaliser le même inventaire, en simultané, depuis plusieurs appareils différents.

Chaque action est immédiatement visible par les autres utilisateurs connectés. Fini les conflits de version et les doubles saisies.

💻 100 % web, zéro installation

Thot est une application web : aucun téléchargement, aucune mise à jour à gérer, aucune application à installer sur les appareils de vos utilisateurs. Un simple navigateur suffit, sur ordinateur, tablette ou smartphone (IOS comme Android).

Comment ça marche ?

Trois étapes simples, du paramétrage à l'usage quotidien.

1. Paramétrez

Créez vos inventaires, importez vos objets, définissez vos rôles et vos fréquences de contrôle.

2. Vérifiez

Vos équipes réalisent les inventaires depuis un téléphone, une tablette ou un ordinateur.

3. Pilotez

Le tableau de bord remonte les alertes : péremptions, objets manquants, incidents, entretiens à venir.
